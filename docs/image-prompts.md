# GPT-Image-2 配图提示词库

> 用 [gpt-image-2-style-library] 技能的模板体系编写。生成后把图片放入 `public/covers/`，
> 并在文章 frontmatter 里加 `cover: /covers/<文件名>.png` 即自动生效。
> 缺失封面时站点会自动使用极光渐变占位，不影响发布。

**通用约束（所有提示词共用，放在末尾）**：

```
画面中不要出现任何文字、字母、数字、水印、logo。边缘不要出现裁切半截的几何体。
输出比例 16:9，分辨率 1600×900，PNG 格式。
```

## 使用流程

1. 打开 GPT-Image-2，粘贴「提示词 + 通用约束」生成图片
2. 保存到 `public/covers/<文件名>.png`
3. 在对应文章 frontmatter 加一行：`cover: /covers/<文件名>.png`
4. `npm run dev` 检查封面渲染效果

## 生成自己的封面

新文章配图时，套用同一模板骨架，替换三处即可：

- **主体**：用 1–2 个具象物体隐喻文章主题（如「数据库」→ 发光的层叠圆盘）
- **配色**：保持深底 + 靛蓝/紫/青光斑的站点基调，换主色只换光斑颜色
- **构图**：中央主体 + 漂浮小元素 + 柔焦背景，是已验证的稳定构图
