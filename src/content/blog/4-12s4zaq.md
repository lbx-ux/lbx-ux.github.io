## 二、热身：哈希表、随机函数、有序表

### 2.1 哈希表

Java 里就是 `HashMap` / `HashSet`。左神强调三点：

- **单次增删改查时间复杂度 O(1)**（常数时间，扩容均摊后仍是常数级），面试中当黑盒直接用，不用手写；
- 设计题时先问自己"这题要不要快速查/去重/建映射"，要就上哈希表，典型如第 7 节的 `原节点 → 克隆节点` 映射；
- 哈希表**不保序**，要序就用有序表。

### 2.2 随机函数

`Math.random()` 返回 [0, 1) 均匀分布的 double，O(1)。`(int)(Math.random() * k)` 等概率返回 [0, k) 的整数——第 2 讲快排 3.0 的随机 pivot 就靠它。左神提醒：随机化是"把最坏情况变成概率事件"的通用手段，后面随机化算法还会反复用。

### 2.3 有序表

红黑树、AVL 树、SB 树（Size-Balanced Tree）、跳表等实现的"带排序的表"，Java 里是 `TreeMap` / `TreeSet`。单次操作 **O(log N)**。比哈希表多出来的能力都来自"序"：查第 k 小、前驱后继、某个范围内的所有 key。左神定位：和哈希表一样当黑盒用，**手写红黑树是高级班内容**，基础阶段会用、说清复杂度即可。

> 一句话对比：哈希表 O(1) 但无序；有序表 O(log N) 换"序"。选谁看要不要序。

## 三、反转单链表与双链表

链表第一基本功。核心是**三指针**：`pre` 记前驱、`next` 记后继，`cur`（这里直接用 head 当 cur）把指针掉头。

![反转链表三指针](/covers/4-12s4zaq/reverse_list.png)

```java
public static class Node {
    public int value;
    public Node next;
    public Node(int v) { value = v; }
}

// 反转单链表，返回新头
public static Node reverseLinkedList(Node head) {
    Node pre = null, next = null;
    while (head != null) {
        next = head.next;    // 1. 先记住下一个，防断链
        head.next = pre;     // 2. 指针掉头指向前驱
        pre = head;          // 3. pre 前进
        head = next;         // 4. head 前进
    }
    return pre;              // head 走出 null 时，pre 就是新头
}
```

双链表同理，只是每个节点要同时维护 `next` 和 `last` 两个指针：

```java
public static class DoubleNode {
    public int value;
    public DoubleNode last;
    public DoubleNode next;
    public DoubleNode(int v) { value = v; }
}

public static DoubleNode reverseDoubleList(DoubleNode head) {
    DoubleNode pre = null, next = null;
    while (head != null) {
        next = head.next;    // 记住原后继
        head.next = pre;     // next 掉头
        head.last = next;    // last 指向原后继（反转后它就是后继）
        pre = head;
        head = next;
    }
    return pre;
}
```

复杂度：时间 O(N)，空间 O(1)。左神要求：**闭眼默写，两分钟内不出错**，这是后面所有链表题的手感基础。

## 四、打印两个有序链表的公共部分

两链表各自有序，双指针齐步走：谁小谁前进，相等就打印并一起前进。和第 1 讲 merge 的双指针同源。

```java
public static void printCommonPart(Node head1, Node head2) {
    while (head1 != null && head2 != null) {
        if (head1.value < head2.value) {
            head1 = head1.next;              // 小的追
        } else if (head1.value > head2.value) {
            head2 = head2.next;
        } else {                             // 相等：公共值
            System.out.print(head1.value + " ");
            head1 = head1.next;
            head2 = head2.next;
        }
    }
}
```

时间 O(N + M)，空间 O(1)。

## 五、判断回文链表：三档空间

### 5.1 第一档：整栈，空间 O(N)

全部压栈，出栈顺序就是逆序，和正序逐一对比。代码最简单，面试兜底。

```java
public static boolean isPalindrome1(Node head) {
    Stack<Node> stack = new Stack<>();
    Node cur = head;
    while (cur != null) {          // 全部压栈
        stack.push(cur);
        cur = cur.next;
    }
    while (!stack.isEmpty()) {     // 出栈 = 逆序，与正序对比
        if (stack.pop().value != head.value) {
            return false;
        }
        head = head.next;
    }
    return true;
}
```

### 5.2 第二档：半栈，空间 O(N/2)

快慢指针找到中点，只把**后一半**压栈，再与前一半对比。省一半空间，时间仍是 O(N)。

```java
public static boolean isPalindrome2(Node head) {
    if (head == null || head.next == null) {
        return true;
    }
    Node slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;          // 慢一步
        fast = fast.next.next;     // 快两步
    }
    // fast 到尾时 slow 在中点（偶数个时是上中点）
    Stack<Node> stack = new Stack<>();
    Node cur = slow.next;          // 后一半入栈
    while (cur != null) {
        stack.push(cur);
        cur = cur.next;
    }
    while (!stack.isEmpty()) {
        if (stack.pop().value != head.value) {
            return false;
        }
        head = head.next;
    }
    return true;
}
```

### 5.3 第三档：原地反转后一半，空间 O(1)

快慢指针找中点 → 把后一半原地反转 → 两端往中间对比 → **最后把后一半反转回去恢复原链表**（面试不恢复会扣分，左神特意强调）。

![回文 O(1) 空间法](/covers/4-12s4zaq/palindrome_o1.png)

```java
public static boolean isPalindrome3(Node head) {
    if (head == null || head.next == null) {
        return true;
    }
    Node n1 = head, n2 = head;                 // n1 慢 n2 快
    while (n2.next != null && n2.next.next != null) {
        n1 = n1.next;
        n2 = n2.next.next;
    }
    // n1 停在中点；把后一半反转，并断开
    n2 = n1.next;            // n2 → 后一半第一个节点
    n1.next = null;          // 断开前后
    Node n3 = null;          // n3 当 pre
    while (n2 != null) {     // 反转后一半
        n3 = n2.next;
        n2.next = n1;
        n1 = n2;
        n2 = n3;
    }
    n3 = n1;                 // n3 → 反转后的尾端头（原链表最后一个节点）
    n2 = head;               // n2 → 前一半的头
    boolean res = true;
    while (n1 != null && n2 != null) {         // 两端往中间比
        if (n1.value != n2.value) {
            res = false;
            break;
        }
        n1 = n1.next;
        n2 = n2.next;
    }
    // 恢复：把后一半再反转回去（n3 是反转链的头，含中点）
    n1 = n3.next;
    n3.next = null;
    while (n1 != null) {
        n2 = n1.next;
        n1.next = n3;
        n3 = n1;
        n1 = n2;
    }
    return res;
}
```

> 恢复段的巧妙处：第一次反转时后一半是"接到中点上"一起反的，所以恢复完的链头恰好是中点节点，前一半的尾（中点）自然接上，不用额外连指针。

三档对比：时间都是 O(N)；空间 O(N) → O(N/2) → O(1)。面试先报第三档思路，再问"要不要保原链表"，体现严谨。

## 六、链表分区：从数组版到稳定六指针版

**题意**：给 pivot，把链表分成 <、=、> 三段，段内保持原相对顺序（**稳定**），段间按 <、=、> 拼接。

### 6.1 数组版：O(N) 空间且不稳定

把节点收进数组，对数组做类似快排 1.0 的 partition，再串回链表。快排的 partition 是远距离交换，**不稳定**，这版只能算热身。

```java
public static Node listPartition1(Node head, int pivot) {
    if (head == null) {
        return head;
    }
    int n = 0;
    Node cur = head;
    while (cur != null) { n++; cur = cur.next; }
    Node[] arr = new Node[n];
    cur = head;
    for (int i = 0; i < n; i++) { arr[i] = cur; cur = cur.next; }
    int less = -1, more = n, i = 0;
    while (i < more) {                       // <= 放左，> 放右
        if (arr[i].value <= pivot) {
            Node t = arr[++less]; arr[less] = arr[i]; arr[i++] = t;
        } else {
            Node t = arr[--more]; arr[more] = arr[i]; arr[i] = t;
        }
    }
    for (i = 1; i < n; i++) arr[i - 1].next = arr[i];
    arr[n - 1].next = null;
    return arr[0];
}
```

### 6.2 六指针版：O(1) 空间且稳定

开三条链：小链、等链、大链，各维护头尾指针共六个。原链表逐节点摘下，按值挂到对应链尾（**挂尾天然保序**），最后小→等→大串起来，空链跳过。

![六指针分区](/covers/4-12s4zaq/partition_six.png)

```java
public static Node listPartition2(Node head, int pivot) {
    Node sH = null, sT = null;     // small 头/尾
    Node eH = null, eT = null;     // equal 头/尾
    Node bH = null, bT = null;     // big 头/尾
    Node next;
    while (head != null) {
        next = head.next;          // 先记下个，防断链
        head.next = null;          // 摘下当前节点
        if (head.value < pivot) {
            if (sH == null) { sH = head; sT = head; }
            else { sT.next = head; sT = head; }
        } else if (head.value == pivot) {
            if (eH == null) { eH = head; eT = head; }
            else { eT.next = head; eT = head; }
        } else {
            if (bH == null) { bH = head; bT = head; }
            else { bT.next = head; bT = head; }
        }
        head = next;
    }
    // 串联：小 -> 等 -> 大，空链跳过
    if (sT != null) {
        sT.next = eH;
        eT = (eT == null) ? sT : eT;   // 等链为空，就让小尾直接接大链
    }
    if (eT != null) {
        eT.next = bH;
    }
    return sH != null ? sH : (eH != null ? eH : bH);  // 返回第一个非空链的头
}
```

复杂度：时间 O(N)，空间 O(1)，稳定。这题是"荷兰国旗"的链表稳定版——数组上做不了稳定三分（交换必乱序），链表挂尾却天然稳定，**结构决定算法**，左神喜欢这种对比。

## 七、复制带随机指针的链表：哈希表版与原地版

节点多一个 `rand` 指针，指向链表中任意节点或 null。要求深拷贝。

```java
public static class RandNode {
    public int value;
    public RandNode next;
    public RandNode rand;
    public RandNode(int v) { value = v; }
}
```

### 7.1 哈希表版：O(N) 空间

`map: 原节点 → 克隆节点`。第一遍建克隆，第二遍用 `map.get(cur).next = map.get(cur.next)`、`map.get(cur).rand = map.get(cur.rand)` 接线。查映射 O(1)，总时间 O(N)，空间 O(N)。

```java
public static RandNode copyListWithRand1(RandNode head) {
    Map<RandNode, RandNode> map = new HashMap<>();
    RandNode cur = head;
    while (cur != null) {              // 第一遍：克隆所有节点
        map.put(cur, new RandNode(cur.value));
        cur = cur.next;
    }
    cur = head;
    while (cur != null) {              // 第二遍：接 next 和 rand
        map.get(cur).next = map.get(cur.next);   // get(null) 返回 null，天然处理尾
        map.get(cur).rand = map.get(cur.rand);
        cur = cur.next;
    }
    return map.get(head);
}
```

### 7.2 原地版：O(1) 空间

三步：① 克隆节点插在原节点后面，形成 A→A'→B→B'；② 利用"原节点的 next 就是它的克隆"设置 rand：`cur.next.rand = cur.rand.next`；③ 拆链，奇数位置还原原链、偶数位置收成克隆链。

![原地复制随机链表](/covers/4-12s4zaq/copy_random.png)

```java
public static RandNode copyListWithRand2(RandNode head) {
    if (head == null) {
        return null;
    }
    RandNode cur = head, next;
    // 1) 克隆并插链：A -> A' -> B -> B'
    while (cur != null) {
        next = cur.next;
        cur.next = new RandNode(cur.value);
        cur.next.next = next;
        cur = next;
    }
    // 2) 设 rand：克隆的 rand = 原 rand 的下一个（即 rand 的克隆）
    cur = head;
    while (cur != null) {
        cur.next.rand = (cur.rand != null) ? cur.rand.next : null;
        cur = cur.next.next;
    }
    // 3) 拆链：原链复原，克隆链抽出
    RandNode res = head.next;
    cur = head;
    while (cur != null) {
        next = cur.next.next;                       // 下一个原节点
        cur.next.next = (next != null) ? next.next : null;  // 克隆接克隆
        cur.next = next;                            // 原接原
        cur = next;
    }
    return res;
}
```

> 这题就是 LeetCode 138。哈希表版是"空间换简单"，原地版是"技巧换空间"，面试两版都要会，先写哈希表版保底，有时间再上原地版。

## 八、环检测与入环节点

**题意**：链表可能有环，返回第一个入环节点；无环返回 null。

**快慢指针法**：slow 一步、fast 两步，能相遇则有环；相遇后 **fast 回头部，双方都改走一步**，再次相遇点就是入环节点。

```java
// 返回第一个入环节点，无环返回 null
public static Node getFirstLoopNode(Node head) {
    if (head == null || head.next == null || head.next.next == null) {
        return null;
    }
    Node slow = head.next;             // slow 先走一步
    Node fast = head.next.next;        // fast 先走两步
    while (slow != fast) {
        if (fast.next == null || fast.next.next == null) {
            return null;               // fast 撞到尾，无环
        }
        slow = slow.next;
        fast = fast.next.next;
    }
    fast = head;                       // 相遇后，fast 回头部
    while (slow != fast) {             // 都走一步，再遇即入环点
        slow = slow.next;
        fast = fast.next;
    }
    return slow;
}
```

**为什么第二次相遇是入环点**（左神课上给的推导）：设头到入环点距离 a，入环点到首次相遇点距离 b，环长 c。首次相遇时 slow 走了 a + b，fast 走了 2(a + b)，且 fast 比 slow 多走整数圈：2(a+b) = a+b + k·c → a + b = k·c → **a = (k−1)·c + (c − b)**。c − b 正是"相遇点再走到入环点"的距离，所以从头部和相遇点同速出发，必然在入环点碰上。

> 左神补充：哈希表版也能做（逐个节点入 set，第一个重复的就是入环点），O(N) 空间；快慢指针 O(1) 空间是面试标准答案。数学证明面试不强制，但"会说一句 a = kc − b"很加分。

## 九、两个链表是否相交：分类讨论

**相交的定义**：两个链表共享某个**节点**（之后完全合并，呈 Y 形；不可能 X 形，因为一个节点的 next 唯一）。考虑环之后，一共三大类：

![相交分类讨论](/covers/4-12s4zaq/intersect_cases.png)

1. **都无环**：相交必为 Y 形。判法：各自走到尾，尾节点不同必不交；相同则用"长度差"找第一交点——长链先走差值步，然后齐步走，第一次相等即交点。
2. **一个有环一个无环**：**必不相交**（无环的尾是 null，有环的没有 null 尾，共享节点会导致尾的形态矛盾）。
3. **都有环**：三小类——
   - 入环点相同：环外相交，把入环点当"尾"，套用无环的长度差法；
   - 入环点不同但在同一个环上：在环上相交，返回任一入环点即可。判法：从 loop1 走一圈，途中遇到 loop2 即是；
   - 两个独立的环：不相交。

```java
// 总入口：返回第一个相交节点，不相交返回 null
public static Node getIntersectNode(Node head1, Node head2) {
    Node loop1 = getFirstLoopNode(head1);
    Node loop2 = getFirstLoopNode(head2);
    if (loop1 == null && loop2 == null) {
        return noLoop(head1, head2);          // 都无环
    }
    if (loop1 != null && loop2 != null) {
        return bothLoop(head1, loop1, head2, loop2);  // 都有环
    }
    return null;                              // 一有一无，必不交
}

// 都无环：尾不同必不交；否则长度差法
private static Node noLoop(Node head1, Node head2) {
    Node cur1 = head1, cur2 = head2;
    int n = 0;                                // n = 链1长 - 链2长
    while (cur1.next != null) { n++; cur1 = cur1.next; }
    while (cur2.next != null) { n--; cur2 = cur2.next; }
    if (cur1 != cur2) {
        return null;                          // 尾节点不同，不交
    }
    cur1 = n > 0 ? head1 : head2;             // cur1 走长链
    cur2 = (cur1 == head1) ? head2 : head1;   // cur2 走短链
    n = Math.abs(n);
    while (n-- > 0) cur1 = cur1.next;         // 长链先追平差值
    while (cur1 != cur2) { cur1 = cur1.next; cur2 = cur2.next; }
    return cur1;                              // 第一交点
}

// 都有环：入环点同 → 环外相交；同环不同入点 → 环上相交；否则不交
private static Node bothLoop(Node head1, Node loop1, Node head2, Node loop2) {
    if (loop1 == loop2) {
        // 把入环点当尾，长度差法找环外交点
        Node cur1 = head1, cur2 = head2;
        int n = 0;
        while (cur1 != loop1) { n++; cur1 = cur1.next; }
        while (cur2 != loop2) { n--; cur2 = cur2.next; }
        cur1 = n > 0 ? head1 : head2;
        cur2 = (cur1 == head1) ? head2 : head1;
        n = Math.abs(n);
        while (n-- > 0) cur1 = cur1.next;
        while (cur1 != cur2) { cur1 = cur1.next; cur2 = cur2.next; }
        return cur1;
    }
    Node cur = loop1.next;                    // 从 loop1 出发绕环一圈
    while (cur != loop1) {
        if (cur == loop2) {
            return loop1;                     // 同环，返回任一入环点
        }
        cur = cur.next;
    }
    return null;                              // 两个独立的环
}
```

复杂度：全程 O(N + M)，空间 O(1)。这题的考点不在代码量，在**分类不重不漏**——面试先画图分类再写代码，是左神反复强调的习惯。

## 十、易错点与面试考点速记

| 考点 | 结论 / 提醒 |
|---|---|
| 反转链表 | 三指针 pre/cur/next，先记 next 再掉头；返回 pre |
| 双链表反转 | next、last 两个指针都要掉头 |
| 快慢指针中点 | `fast.next != null && fast.next.next != null`，偶数时停在上中点 |
| 回文三档 | 栈 O(N) / 半栈 O(N/2) / 原地反转 O(1)；O(1) 版必须恢复原链 |
| 分区稳定性 | 数组 partition 不稳定；六指针挂尾稳定 |
| 六指针串联 | 空链要跳过：`eT == null ? sT : eT` 这类边界 |
| 复制随机链表 | 哈希表版 O(N) 空间保底；原地版 A→A'→B→B'，`cur.next.rand = cur.rand.next` |
| 环检测 | 快慢相遇后，头与相遇点同速再遇 = 入环点；a = kc − b |
| 一有一无环 | 必不相交，直接返回 null |
| 都有环三小类 | 入点同（环外 Y）/ 同环异入点（环上）/ 异环（不交） |
| 无环找交点 | 尾不同必不交；长度差法先追平 |
| 哈希表 vs 有序表 | O(1) 无序 vs O(log N) 有序；要序才上有序表 |
