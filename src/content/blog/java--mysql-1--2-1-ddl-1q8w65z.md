# DDL

Data Definition Language, 数据定义语言, 用来定义数据库对象 (数据库, 表, 字段)。

## 1. 数据库操作

### 1. 查询

- 查询所有数据库

  - ```sql
    show databases;
    ```
  
- 查询当前所处的数据库

  - ```sql
    select database();
    
    返回的是1 row in set (0.00 sec) 说明成功进入当前数据库中
    ```

这四个数据库，外面下载安装完数据库，它自带的数据库

<img src="/covers/java--mysql-1--2-1-ddl-1q8w65z/image-20260124205649065.png" alt="image-20260124205649065" style="zoom:50%;" />

### 2. 创建数据库

```sql
create database [ if not exists ] 数据库名 [ default charset 字符集 ] [ collate 排序规则 ];

if not exists 含义：如果这个数据库名称不存在，我就创建，如果存在，就不执行任何操作
创建成功会出现Query OK, 1 row affected (0.01 sec)这段字符
推荐字符集：utf8mb4
```

注意：在同一个数据库服务器中，不能创建两个名称相同的数据库，否则将会报错。

### 3. 删除数据库

```sql
drop database [if exists] 数据库名；

if exists含义：如果数据库存在，再执行删除，否则不执行删除。
```

### 4. 使用数据库

```sql
use 数据库名;

会进入到数据库里面，然后就可以实现对表的操作
```

上述语法中的database，也可以替换成schema

### 4. 创建表结构

```sql
CREATE TABLE 表名（  
	字段1 字段1类型 [约束] [COMMENT 字段1注释]，  
	字段2 字段2类型 [约束] [COMMENT 字段2注释]，  
	字段3 字段3类型 [约束] [COMMENT 字段3注释]，  
	……  
	字段n 字段n类型 [约束]    [COMMENT 字段n注释]  
)[COMMENT 表注释]；

#[...] 内为可选参数，最后一个字段后面没有逗号
```

## 3. 表操作-数据类型

MySQL中的数据类型主要分为三类：数值类型、字符串类型、日期时间类型。

### 1. 数值类型

|       类型       | 大小  |        有符号的范围         | 无符号（unsigned）的范围 |              描述              |
| :--------------: | :---: | :-------------------------: | :----------------------: | :----------------------------: |
|     tinyint      | 1字节 |        （-128，127）        |        （0，225）        |            小整数值            |
|     smallint     | 2字节 |      （-32768，32767）      |       （0，65535）       |            大整数值            |
|    mediumint     | 3字节 |    （-8388608，8388607）    |     （0，16777215）      |            大整数值            |
| **int或integer** | 4字节 | （-2147483648, 2147483647） |    （0, 4294967295）     |            大整数值            |
|      bigint      | 8字节 |      （-2^63, 2^63-1）      |      (0， 2^64-1）       |           极大整数值           |
|    **float**     | 4字节 |                             |                          | 单精度浮点数值（7位有效数字）  |
|    **double**    | 8字节 |                             |                          | 双精度浮点数值（15位有效数字） |
|     decimal      |       |                             |                          |      小数值（精确定点数）      |

### 2. 字符串类型

|    类型     |         大小          |             描述             |
| :---------: | :-------------------: | :--------------------------: |
|  **char**   |      0-255 bytes      |  定长字符串（需要指定长度）  |
| **varchar** |     0-65535 bytes     |  变长字符串（需要指定长度）  |
|  tinyblob   |      0-255 bytes      | 不超过255个字符的二进制数据  |
|  tinytext   |      0-255 bytes      |         短文本字符串         |
|    blob     |    0-65 535 bytes     |    二进制形式的长文本数据    |
|    text     |    0-65 535 bytes     |          长文本数据          |
|  mediumlob  |  0-16 777 215 bytes   | 二进制形式的中等长度文本数据 |
| mediumtext  |  0-16 777 215 bytes   |       中等长度文本数据       |
|  longblob   | 0-4 294 967 295 bytes |   二进制形式的极大文本数据   |
|  longtext   | 0-4 294 967 295 bytes |         极大文本数据         |

char和varchar的区别：

- char：固定长度，适合长度不变的数据
  - 存储方式：占用n个字符的固定空间，不足的补空格
  - 空间占用：固定，可能浪费空间（如 N=10存2个字符，浪费8个字符的空间）
  - 查询效率：高(固定长度，数据库可快速定位行位置）
  - 尾部空格处理：存储时自动补空格，查询时自动去掉尾部空格
- varchar：可变长度，适合长度变化的数据
  - 存储方式：占用实际字符数+1个字节（一个字节用于存长度）
  - 空间占用：可变，节省空间（如N=10存2个字符，仅占2+1=3字节)
  - 查询效率：稍低（需先读长度信息，再读数据）
  - 尾部空格处理：存储时保留尾部空格，查询时也保留

## 4. 表操作-修改

### 1. 添加字段(add)

```sql
alter table 表名 add 字段名 类型（长度） [comment 注释] [约束]
```

### 2. 修改数据类型(modify)

```sql
alter table 表名 modify 字段名 新数据类型
```

### 3.修改字段名和字段类型(change)

```sql
alter table 表名 change 旧字段名 新字段名 类型[comment 注释][约束]
```

### 4. 删除字段(drop)

```sql
alter table 表名 drop 字段名
```

### 5. 修改表名(rename)

```sql
alter table 表名 rename to 新表名
```



## 5. 表操作-删除

**1. 删除表**

```sql
drop table [if exists] 表名

只有表名存在时才会删除该表，表名不存在，则不执行删除操作（如果不加该参数项，删除一张不存在的表，执行将会报错)
```

**2. 删除指定表，并重新创建该表**

在删除表的时候，表里面的数据会被全部删除，重新创建该表的时候就会创建一个全新的表，里面没有以前的数据

```sql
truncate table 表名
```
