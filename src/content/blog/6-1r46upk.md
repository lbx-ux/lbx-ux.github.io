## 二、图的表示：点边表

```java
// 点：值、入度、出度、直接邻居、连出去的边
public static class Node {
    public int value;          // 点的编号/值
    public int in;             // 入度
    public int out;            // 出度
    public ArrayList<Node> nexts;   // 直接邻居
    public ArrayList<Edge> edges;   // 从自己出发的边
    public Node(int v) { value = v; nexts = new ArrayList<>(); edges = new ArrayList<>(); }
}

// 边：权、从哪来、到哪去
public static class Edge {
    public int weight;
    public Node from, to;
    public Edge(int w, Node f, Node t) { weight = w; from = f; to = t; }
}

// 图：点表（编号→点）+ 边集合
public static class Graph {
    public HashMap<Integer, Node> nodes;
    public HashSet<Edge> edges;
    public Graph() { nodes = new HashMap<>(); edges = new HashSet<>(); }
}
```

![点边表表示](/covers/6-1r46upk/graph_structure.webp)

这套表示对**有向/无向、带权/无权**都适用：无向边存成两条方向相反的有向边即可。左神提醒：Edge 类若要放进 HashSet/排序，需重写 equals/hashCode 或自定义比较器。

## 三、BFS 与 DFS

两个遍历的共同细节：**用 HashSet  记录"进过队/栈"的节点，且登记的时机是入队/入栈那一刻，不是弹出时**。弹出时才登记会导致同一节点被多次入队。

### 3.1 BFS：队列

```java
public static void bfs(Node start) {
    if (start == null) return;
    Queue<Node> queue = new LinkedList<>();
    Set<Node> set = new HashSet<>();
    queue.add(start);
    set.add(start);                 // 入队即登记
    while (!queue.isEmpty()) {
        Node cur = queue.poll();
        System.out.print(cur.value + " ");       // 弹出才打印
        for (Node next : cur.nexts) {
            if (!set.contains(next)) {           // 没登记过才入队
                set.add(next);
                queue.add(next);
            }
        }
    }
}
```

### 3.2 DFS：栈

```java
public static void dfs(Node start) {
    if (start == null) return;
    Stack<Node> stack = new Stack<>();
    Set<Node> set = new HashSet<>();
    stack.push(start);
    set.add(start);
    System.out.print(start.value + " ");         // 入栈即打印（头先）
    while (!stack.isEmpty()) {
        Node cur = stack.pop();
        for (Node next : cur.nexts) {
            if (!set.contains(next)) {
                set.add(next);
                stack.push(cur);        // 当前节点压回，之后还要继续展开它
                stack.push(next);       // 只展开一个邻居就深入
                System.out.print(next.value + " ");
                break;                  // 深度优先：一次只走一条岔路
            }
        }
    }
}
```

DFS 的"压回 cur + break"是手写版的关键：模拟递归"一条路走到黑，回来再走下一条"。

## 四、拓扑排序：入度表法

**题意**：有向无环图（DAG），要求每个节点都排在其所有前驱之后。应用：编译顺序、课程先修、任务调度。

**算法**：① 统计所有点入度，把**入度 0** 的点入队；② 出队一个打印，并把其所有邻居入度 −1，减到 0 就入队；③ 重复到队空。

![拓扑排序入度表](/covers/6-1r46upk/topo_sort.webp)

```java
// 只适用于有向无环图；不破坏原图入度（用副本表）
public static List<Node> sortedTopology(Graph graph) {
    Map<Node, Integer> inMap = new HashMap<>();      // 点 → 剩余入度
    Queue<Node> zeroQueue = new LinkedList<>();      // 入度 0 的点
    for (Node node : graph.nodes.values()) {
        inMap.put(node, node.in);
        if (node.in == 0) zeroQueue.add(node);
    }
    List<Node> result = new ArrayList<>();
    while (!zeroQueue.isEmpty()) {
        Node cur = zeroQueue.poll();
        result.add(cur);
        for (Node next : cur.nexts) {
            inMap.put(next, inMap.get(next) - 1);    // 去掉 cur 这条入边
            if (inMap.get(next) == 0) {
                zeroQueue.add(next);
            }
        }
    }
    return result;
}
```

> 若 result 大小 < 点数，说明图里有环（环上所有点入度永远减不到 0）——拓扑排序顺手能**判环**。

## 五、并查集：路径压缩 + 按大小合并

并查集支持两种操作：**查询两元素是否同集合**、**合并两集合**。左神版用"元素 → 父"的哈希表表示森林，代表元素就是往上爬到顶的那个。

两个优化：① **按大小合并**（小集合挂到大集合下面，控制树高）；② **路径压缩**（find 时把一路上所有节点直接挂到代表下面）。均摊复杂度接近 O(1)（反阿克曼函数，面试说"近似常数"即可）。

![并查集路径压缩](/covers/6-1r46upk/union_find.webp)

```java
public static class UnionFind<V> {
    HashMap<V, V> father;     // 元素 → 父
    HashMap<V, Integer> size; // 代表 → 集合大小（只有代表的有效）

    public UnionFind(List<V> values) {
        father = new HashMap<>(); size = new HashMap<>();
        for (V v : values) {
            father.put(v, v);          // 初始各自为代表
            size.put(v, 1);
        }
    }

    // 找代表 + 路径压缩：先收集一路节点，再统一挂到代表下
    private V findHead(V v) {
        Stack<V> path = new Stack<>();
        while (v != father.get(v)) {
            path.push(v);
            v = father.get(v);
        }
        while (!path.isEmpty()) {
            father.put(path.pop(), v); // 一路节点直接挂代表
        }
        return v;
    }

    public boolean isSameSet(V a, V b) {
        return findHead(a) == findHead(b);
    }

    public void union(V a, V b) {
        V ha = findHead(a), hb = findHead(b);
        if (ha != hb) {
            // 小的挂大的下面
            V big = size.get(ha) >= size.get(hb) ? ha : hb;
            V small = (big == ha) ? hb : ha;
            father.put(small, big);
            size.put(big, size.get(ha) + size.get(hb));
            size.remove(small);
        }
    }
}
```

## 六、Kruskal：边贪心 + 并查集防环

**最小生成树（MST）**：连通无向图，选 n−1 条边把所有点连通且总权最小。

Kruskal 思路：**边按权从小到大排序，逐条试，若这条边的两端还不在同一集合（不构成环）就收下，并合并两端**。用并查集做"判环 + 合并"。

```java
public static Set<Edge> kruskal(Graph graph) {
    int n = graph.nodes.size();
    UnionFind<Node> uf = new UnionFind<>(new ArrayList<>(graph.nodes.values()));
    // 边按权升序（小根堆或排序均可）
    PriorityQueue<Edge> heap = new PriorityQueue<>(Comparator.comparingInt(e -> e.weight));
    heap.addAll(graph.edges);
    Set<Edge> result = new HashSet<>();
    while (!heap.isEmpty()) {
        Edge edge = heap.poll();               // 当前最小边
        if (!uf.isSameSet(edge.from, edge.to)) {  // 不成环才收
            result.add(edge);
            uf.union(edge.from, edge.to);
            if (result.size() == n - 1) break;    // 收满 n-1 条即成树
        }
    }
    return result;
}
```

复杂度 O(E log E)。贪心正确性一句话：全局最小边只要不成环，一定属于某个 MST（交换论证）。

## 七、Prim：点贪心 + 小根堆取最小边

Prim 从**任意一个点**出发，维护"已解锁点集"：每次把解锁点连出去的所有边扔进小根堆，弹出最小边，若它通向**未解锁**的点，就收下这条边、解锁该点；否则丢弃（会成环）。

![Kruskal 与 Prim 对比](/covers/6-1r46upk/mst_compare.webp)

```java
public static Set<Edge> prim(Graph graph) {
    PriorityQueue<Edge> heap = new PriorityQueue<>(Comparator.comparingInt(e -> e.weight));
    Set<Node> unlocked = new HashSet<>();
    Set<Edge> result = new HashSet<>();
    for (Node node : graph.nodes.values()) {   // 外层循环应对森林（多棵树）
        if (!unlocked.contains(node)) {
            unlocked.add(node);
            heap.addAll(node.edges);           // 解锁点的所有边入堆
            while (!heap.isEmpty()) {
                Edge edge = heap.poll();
                Node to = edge.to;             // 无向图存双向边，to 即对端
                if (!unlocked.contains(to)) {  // 通向新点才收
                    result.add(edge);
                    unlocked.add(to);
                    heap.addAll(to.edges);     // 新点的边入堆
                }
            }
        }
    }
    return result;
}
```

复杂度 O(E log E)。与 Kruskal 的对比：**Kruskal 以边为中心（全局排序，适合稀疏图），Prim 以点为中心（局部扩张，适合稠密图）**；两者贪心依据相同——切分定理：横跨"已选/未选"切分的最小边必在 MST 中。

## 八、Dijkstra：距离表 + 锁定最小

**单源最短路**（要求**无负权边**）。维护"源点到各点的最小距离表"：每次从**未锁定**的点里选距离最小的锁定，然后用它**松弛**所有邻居：`dist[to] = min(dist[to], dist[cur] + w)`。

![Dijkstra 距离表](/covers/6-1r46upk/dijkstra.webp)

```java
// 返回 源点 → 各点 的最短距离表
public static HashMap<Node, Integer> dijkstra(Node head) {
    HashMap<Node, Integer> distanceMap = new HashMap<>();
    distanceMap.put(head, 0);
    Set<Node> locked = new HashSet<>();         // 已锁定的点
    while (true) {
        // 1) 未锁定点里选距离最小的
        Node minNode = null;
        int minDist = Integer.MAX_VALUE;
        for (Map.Entry<Node, Integer> e : distanceMap.entrySet()) {
            if (!locked.contains(e.getKey()) && e.getValue() < minDist) {
                minDist = e.getValue();
                minNode = e.getKey();
            }
        }
        if (minNode == null) break;             // 没有可达的未锁定点了
        locked.add(minNode);                    // 2) 锁定：它的最短距离已定案
        // 3) 松弛邻居
        for (Edge edge : minNode.edges) {
            Node to = edge.to;
            int newDist = minDist + edge.weight;
            if (!distanceMap.containsKey(to)) {
                distanceMap.put(to, newDist);   // 第一次见：直接记
            } else {
                distanceMap.put(to, Math.min(distanceMap.get(to), newDist));
            }
        }
    }
    return distanceMap;
}
```

**为什么锁定即定案**（无负权边时）：假设锁定的 minNode 还能被更短路径更新，那条路径必经过某个未锁定点，而未锁定点距离 ≥ minDist，再加非负边权不可能更小——矛盾。有负权边时这个论证失效，所以 Dijkstra 不处理负权（要用 Bellman-Ford/SPFA，左神高级班内容）。

> 工程优化：选最小那步用"小根堆 + 距离更新（堆改值）"可降到 O(E log N)，左神课上给了手写加强堆版本；面试写上面的线性选最小版（O(N² + E)）足够，稠密图反而更优。

## 九、易错点与面试考点速记

| 考点 | 结论 / 提醒 |
|---|---|
| 表示法 | 先转点边表；无向边存两条反向边 |
| BFS/DFS 防重 | set 在**入队/入栈时**登记，不是弹出时 |
| DFS 手写 | 压回 cur + break，一次只展开一个邻居 |
| 拓扑排序 | 只适用 DAG；入度副本表；result 不满 = 有环 |
| 并查集 | 路径压缩 + 按大小合并，均摊近 O(1) |
| Kruskal | 边排序 + 并查集判环；收满 n−1 条停 |
| Prim | 点解锁 + 边入堆；弹到已解锁点丢弃 |
| 稀疏 vs 稠密 | Kruskal O(E log E) 偏稀疏；Prim 堆版同阶，数组版 O(N²) 偏稠密 |
| Dijkstra 前提 | **无负权边**；锁定即定案 |
| Dijkstra 松弛 | `dist[to] = min(dist[to], dist[cur] + w)` |
| 负权边 | Dijkstra 失效 → Bellman-Ford / SPFA |
| MST 贪心依据 | 切分定理：横跨切分的最小边必在 MST |
